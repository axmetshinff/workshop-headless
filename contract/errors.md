# Коды ошибок API

Фронт принимает решения по `errors[].code`. Код — часть контракта: переименовать его — то же, что переименовать поле ответа. Текст `message` может меняться.

| Код | HTTP | Когда | Что делает клиент |
| --- | --- | --- | --- |
| `INVALID_SORT` | 400 | неизвестное поле сортировки | выбрать `id` или `name` |
| `INVALID_ORDER` | 400 | неверное направление или `order` указан без `sort` | передать `asc` либо `desc` вместе с `sort` |
| `INVALID_INCLUDE` | 400 | неизвестная связь или неверная форма параметра `include` | исправить список связей |
| `PRODUCT_NOT_FOUND` | 404 | товара с таким `id` нет или он неактивен | экран «Товар недоступен», ссылка в каталог |
| `PRODUCT_NOT_AVAILABLE` | 422 | `productId` не является доступным для покупки товаром или предложением | оставить корзину без изменений, показать ошибку у товара |
| `BASKET_ITEM_NOT_FOUND` | 404 | позиции с таким `id` нет в корзине текущего посетителя | перечитать корзину |
| `BASKET_SAVE_FAILED` | 500 | модуль `sale` не сохранил изменение корзины | не менять локальную корзину, разрешить повторить запрос |

Ответы без кода из этой таблицы:

- `404`, `status: "error"`, `message: "Endpoint not found"` — такого адреса в `/api/v1` нет: запрос перехватил catch-all маршрут.
- `400` с кодами `productId` и `quantity` — Request DTO не прошёл валидацию. На локальном стенде с `exception_handling.debug = true` ядро дополнительно показывает техническую ошибку с кодом `0`; на проде её нет.
- `403`, `code: "invalid_csrf"` — токен не передан, неверен или относится к другой сессии. Новый токен приходит в `X-Bitrix-New-Csrf` и `customData.csrf`.
- `415`, `code: "invalid_content_type"` — мутация с JSON пришла без `Content-Type: application/json`.
- `500` и HTML без конверта — сервер упал до контроллера. Тело не разбираем.
- `200`, `status: "error"`, `code: 0` и `message: "Internal server error."` — исключение в действии на проде (`exception_handling.debug = false`). Подробности — в логе сервера.

Новый код ошибки добавляется сразу в три места: `lib/Public/Enum/ErrorCode.php`, HTTP-статус в `ErrorCode::httpStatus()`, строка в этой таблице.
